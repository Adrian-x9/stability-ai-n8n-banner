# 🌌 AI-Powered n8n Banner Generator

A lightweight, efficient Python script that leverages the **Stability AI REST API** to generate high-quality, futuristic visualizations of workflow automation systems (inspired by n8n). 

This tool was created to automate the generation of digital assets for personal branding (LinkedIn banners, desktop wallpapers) without the need for manual graphic design.

## 🚀 Features
* **REST API Integration:** Directly communicates with Stability AI's `v2beta/stable-image/generate/ultra` endpoint.
* **Prompt Engineering:** Uses a highly detailed, optimized prompt to generate cinematic, cybernetic neural network visuals (sapphire blue, purple, vibrant teal).
* **Business Process Automation:** An example of solving a real-world asset creation problem using code and AI.

## 🛠️ Requirements
* Python 3.x
* `requests` library
* Stability AI API Key
